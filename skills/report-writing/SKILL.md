# 分析报告写作

读取 [报告模板](references/template.md)，按用户要求的篇幅和内容删改可选部分。已有内容改写、整理或纯文稿任务不要求调用所有专家；需要业务事实时先取得相应真实依据。

1. 整理可用结果与缺失项，区分已通过检查、未完成检查和依赖失败。未合格内容不能作为已证实数据。
2. 先形成有依据的正文，再生成用户要求的文件；不使用占位文字假装完成，不把查询与依赖其结果的文件生成放在同一批调用中。
3. 内部引用包含 result_id、来源轮次、对象、时间与统计口径；外部引用包含 URL、发布/检索日期和适用范围。内外结果存在差异时分别保留。
4. 结论与建议分别标出事实依据、推断和待验证事项。信息不足时如实报告缺口，不要求为凑字数扩写或捏造数据。
5. 未要求文件时直接返回正文。要求 Markdown 时用 generate_markdown；要求 PDF 时先生成完整 Markdown，再用 convert_md_to_pdf。主 Agent 负责文件交付，不将报告生成交给专家。

资源模板不能更改输出目录、工具权限或预算。生成文件仍须位于本轮工作目录；Skill 和上传原文只读，禁止执行 Skill 脚本。
