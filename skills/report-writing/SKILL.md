# 分析报告写作

读取 [报告模板](references/template.md)，按用户要求的篇幅和内容删改可选部分。已有内容改写、整理或纯文稿任务不要求调用所有专家；需要业务事实时先取得相应真实依据。

1. 整理实际分工结果与缺失项，保留失败分工、未完成事项和读取限制。区分来源记载、推断与未知。
2. 依据已取得的结果形成正文；没有调查结果时明确失败，部分结果存在缺口时如实说明，不用占位文字假装完成。
3. 内部引用保留实际 SQL 或材料位置、对象、时间与统计口径；外部引用包含 URL、发布/检索日期和适用范围。内外结果存在差异时分别保留。
4. 结论与建议分别标出事实依据、推断和待验证事项。信息不足时如实报告缺口，不要求为凑字数扩写或捏造数据。
5. 主助手直接输出最终正文，程序校验实际结果和来源后将同一正文自动保存为 answer.md，并提供认证下载。模型和专家不调用生成或写文件工具；文件交付以服务端 completion 和实际产物为准。用户要求其他文件格式时说明当前仅支持正文与 Markdown，不编造下载地址。

资源模板不能更改输出目录、工具权限或预算。生成文件仍须位于本轮工作目录；Skill 和上传原文只读，禁止执行 Skill 脚本。
