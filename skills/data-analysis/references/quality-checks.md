# 数据质量与口径参考

## 数据与覆盖

确认每行代表什么、主键和时间字段是什么，区分全量、抽样、预览及分页结果。按工具实际返回范围报告行数；SQL 的 LIMIT 和文件前五行不能用于推断总体。跨表关联前核对键的唯一性，防止一对多连接重复累计。

## 缺失、重复与异常

- 缺失不等于零；说明排除、保留或填补规则及其对分母的影响，不无依据填值。
- 只按业务键与任务定义判断重复；同名或同金额记录不自动等于重复。
- 异常可能是真实业务变化；先核查单位、采集与口径，不为获得平滑趋势直接删去。
- 样本或类别规模明显不同时，同时报告数量与比率，避免只比较总量。

## 计算口径

- 比率聚合通常使用汇总分子除以汇总分母，不能直接平均各组比率；只有分析目标明确要求等权时才用等权平均。
- 相对变化为（本期－基期）/基期；基期为零时标记不可计算，不返回无穷或任意百分比。
- 比率从 10% 到 12% 是增加 2 个百分点、相对增加 20%；区分两种表达。
- 同比、环比需说明同长度期间、完整与未完整周期、时区及单位；金额核对币种、退款与税费，电商细节按需读取 ecommerce-analysis 的指标参考。

## 可复核结果

保留数据源、范围、筛选、聚合粒度、公式或实际 SQL 和舍入方式。区分没有记录、记录为零、缺少权限及依赖失败；不把无法取得数据报告为零。推断或检验只能在相应方法确实执行且条件满足时报告。
