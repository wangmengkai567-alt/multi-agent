# 数据分析

先明确分析对象、数据来源、字段含义、观察粒度、时间与时区、单位及比较基准。不得把样本预览、搜索片段或模型估计当成完整数据；已有可靠结果可复用，但保留所属轮次与来源。

1. 主 Agent 使用文件读取工具取得上传数据，数据库分析交给 db。db 先用 get_table_data 确认真实字段，再用允许的只读 SQL 计算；子助手只完成分派环节，不再委派或生成整份报告。
2. 在聚合、比率、分组比较或异常判断前读取 [数据质量与口径参考](references/quality-checks.md)。确认缺失值、重复键、样本覆盖和筛选口径；未经授权不修改源数据，清洗规则需可解释。
3. 用实际工具结果支撑计算，保留 result_id、SQL 或可复核的公式、输入及单位。小规模人工计算应明确标注；当前没有任意 Python 执行工具，不声称运行过代码、统计检验或绘图。
4. 先给描述性结果，再解释差异与可能原因。区别绝对变化、相对变化和百分点，相关性不直接支持因果；缺少比较组、样本不足或数据被截断时限制结论。
5. 按问题返回结果、口径、证据与限制。需要完整电商诊断时结合 ecommerce-analysis，需要正式报告时结合 report-writing；无需因此自动检索市场信息或调用全部助手。

当前 Excel 读取仅返回首个工作表的前五行预览和统计描述，无法据此完成任意分组、跨表关联或逐行清洗；所需数据不可见或当前工具无法完成计算时，明确缺口并请求可读明细或所需聚合结果，不伪造全量分析。

Skill 及资源只读，不增加计算工具或脚本执行能力，不更改只读 SQL、文件权限、输出目录和调用预算。
