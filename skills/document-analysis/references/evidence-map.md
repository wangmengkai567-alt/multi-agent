# 文档证据参考

## 引用与提取

需要可审计提取时按“文件与版本、位置、原文证据、提取结果、限制或疑问”记录。位置优先使用实际返回的页码或行号，否则用章节标题及短引文定位。保留单位、日期、主体、条件和例外；数字不能脱离表头、脚注和定义单独引用。

## 版本及跨文档对照

先确定比较基准和版本先后关系，再按同一主题对齐条款，区分新增、删除、修改及表达调整。没有拿到完整旧版或新版时，只说明可见范围内的差异，不宣称没有其他变化。文档之间的矛盾需同时给出证据，不能默认新文件必然取代旧文件。

## 覆盖范围

标明未读取页、未提取表格、缺失附件和不可识别区域。分页读取只支持已经覆盖的部分；需要全文结论时先补齐必要内容。Word 段落提取和 PDF 文本提取不能证明原始版式、图表或脚注已被理解；关键依据位于这些区域时应暂停相应结论，说明需要的材料。
