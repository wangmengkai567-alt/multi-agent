# 经营指标口径参考

以下定义用于确认口径，不替代真实数据库字段、公司定义或查询证据。

| 指标 | 建议计算方式 | 必须记录 |
|---|---|---|
| 净销售额 | 实付金额减退款金额 | 币种、退款记账日期、含税/运费范围 |
| 订单量 | 按有效订单 ID 去重计数 | 订单状态、取消单和退款单处理 |
| 客单价 | 同口径销售额 / 同口径订单量 | 分子分母的日期和订单范围一致 |
| 转化率 | 成交用户数 / 有效访问用户数 | 用户去重范围、流量来源、归因窗口 |
| 同比或环比 | (本期值 - 基期值) / 基期值 | 基期区间、零分母处理、可比天数 |

时间过滤优先采用明确的半开区间 [开始时间, 结束时间)，注明时区；日期字段与退款归属日期不能混用。不存在的字段或无法确认的定义应列为缺失项，不得自行填值。

SQL 返回行数受运行时上限控制。抽样或截断的明细不能直接视为总体；优先在数据库内完成受允许的聚合，并注明聚合和筛选条件。零分母返回不可计算，不能直接写为 0%。

内部数字引用本轮 result_id、查询对象、统计口径与时间；外部来源记录 URL、发布/检索日期、地域及样本范围。口径不同的数据分别列示。
