# 基本多智能体执行约定

主助手通过 task 选择 db、document 或 search，并传入完整 description。任务逐个执行，由程序签发独立任务 ID，记录排队、执行、完成、失败与取消状态。模型不填写身份、审核结论或权限。

## 权限和来源

认证、Cookie、Origin、CSRF 与资源归属检查继续生效。每次运行使用独立工作目录；上传文件只读，执行前绑定内容摘要，变化后拒绝读取。数据库只能查询配置的表，连接时校验账号实际只读权限；禁止写入、危险函数和空 SELECT。

禁止联网时不向模型提供搜索助手，并在真实工具边界再次拒绝。网页读取仅接受当前分工已发现的公开域名或用户提供的地址；不同分工不能借用来源。实际工具响应保留 URL、SQL、文档页表行位置及读取限制。摘要不是全文，材料记载不是独立外部核实。

子助手直接返回结果。程序检查它是否有实际工具结果、是否引用了实际输入或工具响应中存在的 URL；不要求研究计划、锚点、逐条事实报告或额外语义审核。该检查不构成对全部自然语言断言的事实证明。

## 预算与资源

config/runtime.yml 控制整轮、各类调用、每回合工具、单任务模型与工具、搜索及网页读取次数，以及请求、工具和整轮时限。计数由程序原子扣减。达到边界后明确停止，不增加预算或更换模型、工具。

只读查询的瞬时错误可在配置额度内重试；参数、权限与永久错误不重试。429 使用真实 Retry-After。模型 SDK 隐式重试关闭，搜索工作进程发送请求前必须取得程序授权；额外的隐式发送会被拒绝。

服务、模型、搜索和专家执行槽继续限制并发与排队。阻塞操作使用受控进程；Windows Job Object 负责子进程及后代回收。取消、超时和关闭后拒绝新动作与迟到结果，持久化终态不能被改成完成。

## 结果与文件

每个分工单独保存实际工具证据与执行结果。已有成功结果不会因其他分工失败而丢失；整体显示部分完成并披露失败。调查没有有效结果时明确失败，不发布成功文件。

程序将最终正文写入 answer.md，UTF-8/CRLF。认证下载的文件字节与保存的正文一致。completion.status 表示分工与交付是否完整，不代表所有业务事实都已独立核验。

后台研究、动态需求图和自动检查点恢复已移除。历史运行和结果的数据库结构及读取保留，既有 jobs.db 不删除、不自动续跑，也不改写历史业务内容。

## 验证

使用 tools.verify_project 执行隔离离线回归；完整保留失败，不豁免旧协议错误。真实验收入口为 tests/manual/stage1_acceptance.py，只执行原第 1 题一次，记录真实委派、工具、来源、终态和 Markdown 字节证据后停止。
