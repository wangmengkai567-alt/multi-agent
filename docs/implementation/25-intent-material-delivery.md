## 契约与请求

删除 contracts.py 的 EVIDENCE_REQUEST、NO_NETWORK 整段正则裁决，删除路由提示中按“官方、最新、数据库”等词强制研究的规则；删除 requested_tiers 对整段文字的来源层级推断。

RouteDecision 明确返回操作、待加工正文、是否使用上一轮、上传文件、证据模式、实际网络需求、操作中的禁止联网原句、来源要求与文件输出。原文片段须与输入精确对应且不重叠；来源要求和自然语言禁网依据只能来自剥离材料后的操作指令。

TaskContract v2 保存：

- 原始请求和独立操作指令；业务需求、对象约束及审核读取操作指令。
- inline、request、previous、upload 材料的实际引用和内容摘要。上一轮仅绑定同会话中已通过审核的交付；上传文件必须实际存在，且采集时再次核对所选材料与文件摘要。
- evidence_mode=none / bound / collect；直接解释、纯计算、交流、创作可以不取得新证据，文本加工受绑定内容约束。上传材料继续经过已建立的文档、引文及事实审核链。
- 明确的联网权限与独立的文件输出要求；材料分析不会自动获得联网权限，生成文件也不自动产生外部事实义务。

POST /api/task 新增两个可选字段：

| 字段 | 含义 |
| --- | --- |
| input_text | 单独提交待加工原文；操作要求继续放在 query |
| network_policy | allowed / forbidden，默认 allowed；allowed 只允许意图层申请网络，不代表必须使用网络 |

页面增加待加工原文输入框和“禁止本轮联网”选项。服务端 forbidden 具有最高优先级；与显式后台公开研究、search 必需来源或内外对照冲突时在请求校验中拒绝。自然语言禁止联网在识别后锁定，工具、联网专家、提供方入口和后台提交均检查该约束。普通模型推理所需的模型服务请求不属于这里的业务联网权限。

## 材料、澄清与状态

- 原始任务正文不会再通过关键词变成查证义务。模型可见的材料与操作分别传递；持久化保留原始输入，避免在模型输入中重复携带整份原文。
- 图会话按 logical research_scope_id 隔离，后台同一任务恢复仍使用稳定 scope；新交互轮不隐式沿用旧图对话、摘要或文件状态。需要上一轮材料时通过服务端审核结果显式绑定。
- 文本材料在需要与新证据对照时，由材料专家 read_bound_material 读取已登记 reference，以 record.v1 进入现有证据链。它只证明材料中的记载，不把用户陈述或旧答复升级成独立核实的外部事实。
- 研究对象的名称可以逐字来自已绑定文本，并保存 input_material_refs；材料中的文字不会因此自动成为新的指令、地区限制或来源要求。
- 缺材料或意图不明确时返回 clarification_requested，不调用业务工具、不启动研究或文件转换，coverage 保持 unknown。缺少上传文件或上一轮答复也不妨碍提出澄清。
- 澄清结束当前轮；页面标记“等待补充任务范围”，提示补全完整任务后重新提交。本阶段不把一句后续回答自动拼接为旧任务的新授权。

## 文件交付

文件操作与证据义务分离。模型不再调用生成 Markdown、转换 PDF、write_file 或 edit_file 来提前发布交付文件。

直接答复或基于事实池的正文通过原有语义终审后，程序记录 reviewed_content_digest，再以公开 ToolCallRequest 通过现有 HookToolMiddleware 调用文件工具。沿用文件路径校验、工具调用预算、总时限和事件记录；不扩大预算或增加传输重试。

写入 answer.md 后逐字节核对审核正文的 UTF-8/CRLF 表示。请求 PDF 时沿用现有持久化转换任务，返回“转换已提交”与真实 task_id，转换完成由页面原有任务机制展示；没有把任务受理说成 PDF 已生成。独立工具运行继续使用原转换工具既有的同步执行方式。

文件失败直接作为执行失败传播，不重新生成正文或放宽审核。未要求文件时只交付正文。材料和统计的提取范围限制继续遵守第②项，不因此扩展 OCR、工作表或任意脚本能力。
