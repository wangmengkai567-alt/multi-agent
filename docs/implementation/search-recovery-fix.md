## 修改

1. 检索额度改为整轮共享：普通任务 2 次，调研/报告/内外对照 6 次。配置名称 calls_per_run 和 research_calls_per_run。新委派和内容修订均不重置；网络瞬态重试继续占原槽位。
2. 检查结构错误最多进行一次检查重试，消耗 review/retry 预算，复用同一任务、草稿和真实工具记录。合法 JSON 围栏可直接读取，不消耗重试。仍不合法则明确失败，不自动通过，并阻止搜索助手在本轮被重复委派。内容质量修订次数耗尽后也阻止重新委派，向主助手明确返回 retry_allowed=false。记录字段位置和错误类型，不保存可能含敏感信息的原始校验输入。
3. 同一子任务修订保留草稿和证据；并发子任务之间的证据保持隔离。
4. 额度用尽时保留工具 schema，以 tool_choice=none 禁止调用，防止部分兼容接口在移除 schema 后把工具调用标记写进正文；执行层仍独立拦截超额请求。额度拦截单独标记 search_limit，界面说明新请求未执行、已获准并发请求仍可完成；不计作网络故障，不掩盖真正的失败。
5. Markdown 使用本地固定版本 Marked 18.1.1 与 DOMPurify 3.4.17 渲染和清理，不依赖运行时 CDN。限制可用标签、属性及链接协议，过滤脚本/事件属性；来源链接加 noopener noreferrer。保留温度范围中的单个 ~，仅双 ~~ 表示删除线。第三方来源、版本、校验方式与许可证位于 api/static/vendor/。
